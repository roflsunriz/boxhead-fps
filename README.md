# Boxhead FPS

Three.js 製のブラウザ向け FPS ゲーム。TypeScriptで実装し、開発にはVite、ビルドにはBunのバンドラを使用する。

**[GitHub PagesでBoxhead FPSをプレイ](https://roflsunriz.github.io/boxhead-fps/)**

公開バージョン: **1.3.1**

## ゲーム内容

- WASD 移動 / マウス視点 / クリック長押しのフルオート射撃 / 右クリックでレッドドットADSをトグル / R リロード / Shift ダッシュ / Space ジャンプ
- C でしゃがみ、X でうつぶせをトグル。姿勢に応じて視点高と移動速度が変化する
- F でバリアセルを使用し、充填ゲージと一人称アニメーションの完了後にバリアを 50 回復する
- G でグレネードを投射する。最大所持数は 5 個で、時限爆発の範囲内にいるボットへ距離減衰ダメージを与える
- グレネードは地面や障害物で反射し、爆発地点の接触面へ不規則な焦げ、低い破砕縁、散乱した瓦礫で構成するクレーターを残す。爆発跡は最新20個を保持する
- マップ上にバリアセル、ヘルスキット、グレネードが各 5 個ずつランダム出現し、接近すると取得できる
- 射撃音・被弾音・アイテム取得音・バリア充填音・爆発音と、攻撃元を示す円周ダメージインジケーターを搭載
- リロード時は補助手で古い弾倉を抜き、新しい弾倉を差し戻す一人称アニメーションを再生
- 投げ捨てた弾倉、障害物・地面への弾痕、倒したボットの死体が戦場へ残る。弾倉24個・弾痕128個・死体12体を上限とし、超過した分は古いものから削除して描画負荷を制限する
- プレイヤーが敵を倒すと、敵名付きの撃破システムメッセージを画面上部へ表示
- ヘルスがゼロになると前後左右のいずれかへランダムに倒れ込み、地面へ視点が落ちながら画面全体が赤く染まる死亡演出を搭載
- 全マップに高さ2m以上の遮蔽物を高密度配置。都市のコンテナ・L字壁・タンク、ビーチの大型岩・木壁・監視小屋、地下の大型箱・防爆壁・タンクを利用できる
- チームデスマッチ: 青チーム(プレイヤー + アライボット 3)vs 赤チーム(ボット 4)。先に 20 キルで勝利、死亡後はリスポーン
- ボット AI: ウェイポイントグラフ経路探索、視界による索敵(壁で遮蔽)、被弾時の攻撃者への振り向き・追跡・反撃、個別の体力・弾薬・リロード・ジャンプ・スプリント、Beginner〜Pro のスキルランク(高スキルほど正確かつジグザグ回避を行う)
- ボットはチーム色付きライフルを両腕で構え、巡回中は歩行、交戦移動中は前傾したスプリントへ切り替わり、発砲時は銃の反動・火炎・マズルライトが同期する
- 一人称武器とボット武器は、実開口ハンドガード、レール、リフレックスサイト、着脱マガジン、マズルソケットを持つ共通の手続き型カービンモデルを使用する
- グレネード、医療キット、シールドセル、戦闘ボット、ヤシの木、ヒトデ、都市建築を複合ジオメトリへ更新し、金属・樹脂・ゴム・砂・コンクリート・ファサードへ独立PBRチャンネルを適用する
- 都市の草地と建物前の舗装、地下床に色・法線画像を使い、建物前の舗装には粗さ画像も適用する。地面の細部が近距離でも見える
- 味方ボットは身体と装備の縁を常時シアン色でハイライトし、ヘルメット後頭部のシアンIFFでも背面から識別できる。輪郭とIFFは照準の当たり判定には含まれない
- HUD右上のヘディングアップ式ミニマップは自分を中央に固定し、味方をシアン円、敵を赤い菱形、範囲外のボットを外周へ表示する
- クロスヘアは中央に空間を残した4本線の十字照準で、標的を隠さず見やすさを保つ
- ボットの交戦距離は最大42m。12mを超えると距離に応じて命中率と連射速度が大きく低下し、遠距離から一方的に狙撃されにくい
- 大気プリセット(Sunny / Cloudy / Rainy / Thunderstorm / Night / Beach Sunset / Underground)を読み込みごとにランダム適用。雨・雷フラッシュ・星空・懐中電灯を含む
- Beach Sunset と Underground は雰囲気だけでなくマップ自体が変化する。ビーチは岸へ進む立体波・動く白波・ヤシの木・岩場・ヒトデや魚、アンダーグラウンドはコンクリート天井と柱に囲まれた地下空間
- UI は日本語 / 英語対応(右上の JA/EN ボタンで切替。設定は localStorage に保存)

都市の木はケヤキやクスノキを思わせる広葉樹で、枝分かれした幹から横へ広がる樹冠と、一枚ずつ形のある葉を持ちます。ビーチのヤシは長い小葉が弧を描いて垂れます。

## セットアップ

```powershell
bun install
bunx playwright install chromium
```

必要環境: Bun（CI は 1.3.14、ローカルは 1.4.0 で確認）。E2E 検証には Node.js 26.x と Google Chrome も必要。

## 開発

```powershell
bun run dev
```

`http://localhost:8787` で HMR 有効の開発サーバが起動する。

## ビルドと確認

```powershell
bun run build     # dist/ へバンドル出力(Bun のバンドラ使用。rollup/rolldown 不使用)
bun run preview   # dist/ を 8787 番ポートで配信
```
